# Bank System

A console-based bank management system built with C++ using Object-Oriented Programming (OOP).
The project was built as part of my .NET roadmap journey to practice designing real applications with OOP.

## Features
- Login system with user accounts
- Users and permissions: each user can access only what they are allowed to
- Manage clients: add, delete, update, find, and show all clients
- Transactions: deposit, withdraw, transfer, and show total balances
- Logs: login records and transfer records

## Tech
- Language: C++
- Concepts: classes and objects, encapsulation, abstraction, inheritance, and reusable libraries
- Data is stored in text files

## How to Run
1. Clone the repository:
   `git clone <repository-link>`
2. Open the project in Visual Studio.
3. Build and run the project.
4. Login with your username and password.

## What I Learned
- How to divide a big system into small classes with clear responsibilities
- How to add permissions and validation to an application
- How to extend a system without breaking the old code
